# What's new

## 0.2.0 — 2026-11-25

- **Updates install themselves.** Fil checks for a new version regularly and switches to it on its own — while the window is in the background, or after 10 minutes without typing. Your edits are saved first and you come back to the same place.
- **What's new.** This page, from the command palette (`Ctrl+K` → *What's new*).
- **Installable app.** Install Fil from Chrome or Edge, or with *Install Fil as an app* in the palette. It runs in its own window and works offline.
- **Times in the margin.** Each note's time sits in a column to the left of the text instead of a heading line.
- **Simple dates.** Dates are written `2026-11-25` everywhere.
- **Smarter Ctrl+A.** Selects the current note, then the day, then the whole journal.
- **Cleaner look.** Lighter text selection; tag sheets shown as a card.

## 0.1.0 — 2026-11-23

- First version: a chronological journal in one editor, `#tags` with colors and aliases, topic views with a sheet, open actions and history, a command palette, tag renaming and merging, and your notes as Markdown files in a folder you choose.
