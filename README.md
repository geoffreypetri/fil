# Fil

A free-form, chronological note-taking web app structured by `#tags`. Desktop only (Chrome, Edge).
Notes are plain Markdown files in a folder you choose; Fil runs entirely in the browser.

## Development

```bash
npm install
npm run dev      # http://localhost:5173
npm test
npm run build    # static build in dist/
npm run preview  # serves dist/ at http://localhost:4173/fil/
```

The full documentation is written in the last implementation step.
